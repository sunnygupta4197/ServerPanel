# Delivery Roadmap

## Phase 0: Foundation

- finalize v1 scope
- define domain model
- define action contract model
- define job lifecycle
- define trust boundaries

## Phase 1: Platform Core

- control plane bootstrap
- auth and RBAC
- server registration
- agent heartbeat
- audit logging
- job orchestration base

## Phase 2: Hosting Core

- app/site model
- runtime management
- reverse proxy config generation
- SSL issuance and renewal
- logs and health checks

## Phase 3: Data and Recovery

- database provisioning
- backup creation
- restore workflows
- retention policies

## Phase 4: Hardening

- operational alerts
- permission refinement
- disaster recovery testing
- penetration testing
- release readiness

## MVP Cut Line

The first sellable milestone includes:

- one Linux server connected
- one application deployed
- one domain configured
- one certificate issued
- one database provisioned
- one backup created and restored
- one audit trail proving the full flow
